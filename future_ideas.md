Although the current implementation successfully achieves its primary objectives, several enhancements can be incorporated to further improve system performance, scalability, and usability.

• WireGuard Mesh Networking: 
Integrate optional WireGuard tunnelling as a connectivity layer between mesh nodes, automating VPN mesh setup so nodes can reach each other over the public internet without requiring port forwarding or manual VPN configuration.

• Mobile Application Development
Develop dedicated Android and iOS applications to provide users with seamless access to files, search functionality, and streaming services from mobile devices.

• Delta Synchronization
Implement rsync-style delta synchronization mechanisms to reduce bandwidth consumption and improve file update efficiency.

• Advanced AI Capabilities
Re-introduce AI-assisted file discovery by integrating a locally-hosted language model (such as an Ollama-served model) to enable natural language search queries, content summarisation, and intelligent file categorisation without sending data to external cloud services.

• Collaborative Annotations:
Allow users to add comments, tags, ratings, and annotations to shared files for improved collaboration and knowledge sharing.

• Distributed Metadata Replication:
Replace the single Directory Node registry with distributed metadata replication mechanisms to eliminate centralized metadata dependency.

• Blockchain-Based Audit Trails:
Integrate blockchain technology to maintain immutable records of file access and sharing activities for enhanced transparency and security.

• End-to-End Encryption:
Implement client-side encryption mechanisms that ensure only authorized users can access file content.

• Plugin-Based Architecture:
Develop a plugin framework that allows third-party developers to extend system functionality through custom modules and integrations.

• Public Open-Source Release
Release Files Hub as an open-source project to encourage community contributions, improve feature development, and foster adoption among distributed systems enthusiasts.
